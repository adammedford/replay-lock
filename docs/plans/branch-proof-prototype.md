# Immutable-scalar branch-proof prototype (#125)

Evaluation branch: `prototype/immutable-scalar-branch-proof`, based on the merged partial #106 delivery. This source is retained outside main as an experiment, not approved production import support. [Public acceptance spec #125](https://github.com/adammedford/replay-lock/issues/125) and [decision #123](https://github.com/adammedford/replay-lock/issues/123) define the limits. No named Epic success or completion of #106/#107 follows from passing synthetic tests.

## Question and interface

Can the existing development scan and natural record → review → verify seam distinguish unreachable initializer effects from reachable hazards using only literal primitive facts and initialized immutable module-local bindings, without executing application predicates or modifying source branches?

The prototype proof module returns known primitive values or unknown internally and filters only initialization execution findings. Capture, transform and replay preflight share the analyzer. Imports, lexical bindings, policy directives and callable bodies keep their existing checks. Unknown is not false. Public policy, runtime profiles, V1 and V2 artifact formats remain unchanged. Internal cached-plan keys bind the experimental proof revision without changing the public graph digest; changed source, resolution, physical locators and configuration require current qualification rather than reusing stale facts.

This narrow experiment intentionally excludes environment/secret discovery, property/getter/native-function assumptions, imported constants, mutable bindings, object coercion, loops and interprocedural branch proofs. An outer proved-dead branch may contain a try statement, but a reachable or unknown try/catch is not permission to ignore effects.

Use Node22.19.0/npm11.5.2 and a project-local `npm ci` installation, not another checkout's symlinked dependencies. Install Chromium with `npx playwright install chromium` (Linux additionally needs its system libraries).

## Evidence discipline

Before implementation, the public CLI reported EFFECTFUL_INITIALIZATION for both a constant-false logging initializer and its constant-true opposite in both realms. The prototype must admit only the proven-dead path. Expected fixture completions are literal7/11, not generated by invoking a target to manufacture a case.

Natural application workflows use Node HTTP requests and Chromium button clicks. Their pending observations are inspected before explicit synthetic review. Marker-scoped logging sentinels are installed outside the target before live or replay import and latch a reached effect independently of application catch. A throwaway replay-harness positive control verifies that the sentinel actually fails. This is a test oracle for synthetic logging, not a runtime sandbox or a claim that arbitrary native effects are intercepted. Other reachable native-effect patterns are admission-negative scan controls; blocked application modules are not imported to assert zero counters.

The evaluation must separately report predicate/hazard controls, actual capture/replay, safe-edit verification, stale unsafe-guard preflight, cache/overlay drift, full regressions, both review axes and current pinned application findings. A missing seam or unsupported case is a finding, not a passing test. Final outcomes and source pin are recorded in #125; the command list alone is not evidence of success.

## Compatibility limit

The pinned Epic revision is8473afd804b66dba6a23f317908dc35d1535e90d. The prior [blocker map](../pilots/analyzer-precision-2026-10-01.md) separates Prism's ambient global writes, Sentry's mutable Array.from guard and catch logging, Noble's reachable local table loop and OAuth registration's environment-dependent logging and constructor work. Those constructs are outside this first proof grammar. No package/file allowlist, replay placeholder assumption or default-native-behavior assumption may clear them.

The 2026-10-02 [retained comparison](branch-proof-epic-results.json) finds **20 eligible callables per realm in both baseline and prototype, zero of eleven named targets**. Every named target still reports EFFECTFUL_INITIALIZATION. Node roots are Noble SHA3:29 except forgot-password/signup (Prism:1218) and auth (auth.server.ts:23). Browser root/login/reset-password/note-detail roots are Sentry replay:4019; other roots match Node. The JSON lists every exact target and origin.

Reproduce with the [evaluation harness](branch-proof-epic-scan.mjs):

```sh
node docs/plans/branch-proof-epic-scan.mjs APP_ROOT BASELINE_DIST
```

This is deliberately an **explicit-default-development-conditions structural scan with dotenv metadata excluded**, not a new fully configured application scan or complete fingerprint qualification. It executes no application config hooks or blocked target modules, and its process-local filesystem guard forbids dotenv reads. The application retains earlier pilot instrumentation; unchanged Git status does not assert a pristine checkout or byte-for-byte immutability. Baseline analyzer a0aa766 has identical analysis/options/transform source to merged base0867957. Prototype implementation pin d39383f; the result document and harness are retained in subsequent evidence commits. No application or dependency edits were made by this evaluation.
